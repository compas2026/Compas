# Compas — Marketing Analytics & Paid Ads

A responsive single-page marketing website for Compas, focused on marketing analytics, Google Ads, and Meta Ads.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. Your site will be published at `https://compas2026.github.io/Compas/` once GitHub Pages finishes building.

The contact form prepares an email in the visitor's default email application. To receive enquiries directly without opening an email app, connect a form service or backend and configure the destination email.
